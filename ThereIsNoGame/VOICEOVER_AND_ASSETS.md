# There Is No Game: Semester Edition Voiceover and Assets

This file is the planning sheet for the narrator lines, story beats, and simple assets. The project is inspired by the playful "there is no game" idea, but it is written as a small first-semester web design assignment using separate HTML, CSS, JavaScript, and asset files.

## Voiceover Style

The narrator should sound like a dramatic student trying to convince the player that nothing interactive is happening. Keep the delivery quick, silly, and slightly panicked.

## Voiceover Script

| Moment | Narrator line |
| --- | --- |
| Page loads | "There is no game. Definitely no buttons, mysteries, or suspicious school supplies." |
| Start button clicked | "No. That button is for decoration. Click the title letters if you insist on causing curriculum." |
| Title letters clicked | "Do not click the title. I only know a little JavaScript and it gets nervous." |
| Many title letters clicked | "That title took me ten minutes to type. Please show respect to my keyboard." |
| Title fully falls | "Fine. The title fell. This is still not a game; it is a dramatic typo accident." |
| Story begins | "Please do not draw my school supplies. They are load-bearing supplies." |
| Scissors found | "You found scissors. They are decorative. Sharp decorations. Totally normal." |
| Pencil found | "You found a pencil. That is for writing paragraphs with suspiciously large margins." |
| Screwdriver found | "You found a screwdriver. Please do not open the notebook. It contains unfinished homework." |
| Eraser found | "You found an eraser. It deletes mistakes, unless the mistake is clicking everything." |
| Backpack empty | "The backpack is empty. You even checked the tiny crumb pocket." |
| Scissors selected | "Scissors selected. This is where I remind you not to cut important plot rope." |
| Pencil selected | "Pencil selected. It has the power of one sentence." |
| Screwdriver selected | "Screwdriver selected. The notebook suddenly feels unsafe." |
| Eraser selected | "Eraser selected. It erased nothing because the CSS said no." |
| Rope clicked without scissors | "That string needs scissors. Or patience. Mostly scissors." |
| Rope cut | "You cut the string. The sign has fallen with great educational drama." |
| Screw clicked without screwdriver | "The notebook screws need the screwdriver. The narrator needs a vacation." |
| Screw removed | "One screw is gone. That was probably not on the rubric." |
| Final screw appears | "Only one dramatic screw is left. Do not click it. It has main-character energy." |
| Bug clicked | "You clicked the bug. Congratulations, you are now technical support." |
| Bug clicked again | "The bug is already fixed. That is called debugging. Very professional." |
| Ending | "I told you. There is no game, only a first-semester project wearing a fake mustache." |

## Story Beats

1. The start button refuses to start the game.
2. The player discovers that clicking title letters makes them fall.
3. When all letters fall, the classroom-style game area appears.
4. The player draws backpack cards to unlock simple tools.
5. The pencil updates the story card with a first-semester writing joke.
6. The eraser tries to delete the story but turns into a lesson about mistakes.
7. The scissors cut the rope and drop the "NO GAME" sign.
8. The screwdriver removes notebook screws.
9. A final dramatic screw reveals the ending.
10. A tiny bug can be clicked for a debugging joke.

## How to Playtest

1. Open `index.html` in a browser.
2. Click the fake start button once to hear the narrator complain.
3. Click every title letter.
4. Draw all four backpack cards.
5. Use the pencil and eraser on the story card.
6. Use scissors on the rope.
7. Use the screwdriver on all notebook screws and then the final screw.
8. Click the tiny bug at least once.
