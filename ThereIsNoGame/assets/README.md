# There Is No Game Assets

These tiny SVG assets are simple enough for a first-semester web design project and are used by the backpack tool buttons.

- `scissors.svg` appears when the first backpack card is drawn.
- `pencil.svg` appears when the second backpack card is drawn.
- `screwdriver.svg` appears when the third backpack card is drawn.
- `eraser.svg` appears when the fourth backpack card is drawn.

The rest of the game uses CSS shapes for the rope, sign, notebook, screws, and hidden bug so the project stays easy to edit.
